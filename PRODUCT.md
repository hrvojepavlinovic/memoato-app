# Memoato

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A private memory and trustworthy context product. Preserve what people write,
extract reviewable facts, and retrieve useful context with its original evidence.
Personal memory and AI/team context have equal prominence, as confirmed by Hrvoje.

## Users and Operating Context

People remembering everyday details, and people using AI tools or project/team
workspaces. The app supports direct capture, memory review, recall, category
views, and scoped API/MCP access. Context workspaces expose source connections,
claim review and evidence-backed context packets; communicate current pilot and
read-only boundaries accurately.

## Capabilities and Constraints

- Existing Wasp 0.20 / React / PostgreSQL product. Preserve auth, account
  verification, permissions, original entries and local/encrypted modes.
- Categories, goals, charts and timeline remain available as views.
- Do not claim local-only data reaches cloud AI or promise undeployed integrations.
- Do not change production data or enable source connections for visual QA.
- Implement one Todoist step, validate, deploy through existing CI, then wait for
  Hrvoje's QA before the next step. Mobile quality is required throughout.
- Work in this task without delegation or external notifications.

## Brand Commitments

Extend the approved memoato.com identity into app.memoato.com. Keep Memoato's
existing mark and product name; preserve the distinction between original
entries and derived facts. Avoid unnecessary disclosure triangles and repetitive
boxed content, especially on mobile.
